## 2. 一键脚本层（`launchers/`）

| 脚本                                              | 功能                                                                 |
| ------------------------------------------------- | -------------------------------------------------------------------- |
| `一键启动-日常推荐.cmd`                           | 日常档启动（cpu-gb 4 / ctx 131072 / gen 8192 / budget 32768）        |
| `一键启动-长上下文.cmd`                           | 长上下文档启动（cpu-gb 6 / ctx 262144，其余相同）                    |
| `一键停机-日常推荐.cmd` / `一键停机-长上下文.cmd` | 停机（两者等价，停机不分档）                                         |
| `状态检查.cmd`                                    | 一次性体检：在不在跑 / 是哪档 / 显存内存 / 接口 200 / 真推理是否正常 |
| `start-engine.ps1`                                | 真正的启动逻辑（.cmd 只是壳）                                        |
| `stop-engine.ps1`                                 | 真正的停机逻辑                                                       |
| `status.ps1`                                      | 真正的状态检查逻辑                                                   |

**已实现的安全机制**（每条都是实测撞出来的）：

- ✅ **拦重复启动**：本机实测同一端口能被两台引擎同时绑定且不报错，脚本会先检查并拦截（退出码 3）；
- ✅ **内存预警**：长上下文档在可用内存 < 10 GB 时提醒（25 万 token 要 19 GB）；
- ✅ **启动自检**：不只等 200，还**真发一次推理**，防止"只开了个壳"；
- ✅ **停机清理**：按端口杀 + 按 exe 精确路径清孤儿 + 关窗口壳 + 复查显存/内存归还；
- ✅ **进程级环境变量**：不写注册表、不改系统 PATH、不装任何东西（试错零风险）；
- ✅ **可移植路径**：包路径自动推导，也可 `-PkgPath` 显式指定。

## 3. 聊天页（`launchers/聊天.html`）

单文件、离线、无需安装、中文界面。**所有 CORS 与存储能力都在这台机器上实测过**。

### 3.1 对话能力

| 功能                       | 状态                                                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 流式对话（逐字显示）       | ✅ 实测：一道代码题 1.8 秒 / 65 字 / decode 28.8 t/s                                                                                    |
| 多轮上下文                 | ✅ 实测：追问能承接上文                                                                                                                 |
| **先推理再答（思考模式）** | ✅ 实测：勾选后出现"思考强度（低/中/高）"，思维链流式显示在可折叠框里，答案随后输出，答完自动收起；思考内容**入库保存**，重载后仍可展开 |
| 风格三档                   | ✅ 默认 / 精确（temperature=0，写代码用）/ 发散                                                                                         |
| 停止生成                   | ✅ 中途掐断，已生成部分保留并入库                                                                                                       |
| 错误提示                   | ✅ 引擎没起、端口不对、浏览器拦截 file:// 三种情况分别给可操作提示                                                                      |

### 3.2 会话管理（数据持久化）

| 功能                              | 状态                                                        |
| --------------------------------- | ----------------------------------------------------------- |
| 自动保存每轮问答                  | ✅ 实测：IndexedDB 落库；关标签/重载/停引擎再启动都在       |
| 多会话：新建 / 切换 / 改名 / 删除 | ✅ 实测：切换恢复内容；改名后**头部、侧栏、数据库三者一致** |
| 搜索                              | ✅ 实测：**标题和内容都能搜**                               |
| 标题自动命名                      | ✅ 取第一句话（可改名）                                     |
| 移动/改名文件夹不丢历史           | ✅ 实测：`file://` 存储由所有本地页面共享                   |
| 降级兜底                          | ✅ IndexedDB 不可用时自动退 localStorage                    |

### 3.3 备份与迁移

| 功能                             | 状态                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------- |
| 导出当前 / 导出全部              | ✅ 实测：JSON 可解析，schema `lmchat/1`                                           |
| 导入 JSON                        | ✅ 实测：合并进列表（同 id 自动换新 id，不覆盖）                                  |
| **备份到文件夹**（每轮自动落盘） | 👤 需你授权一次目录；已实测：目录里出现 `<标题>__<id>.json` 实体文件              |
| **自动清理旧标题文件**           | ✅ 实测（模拟目录）：改名后自动删掉同 id 的旧文件，**别的会话与无关文件一律不动** |
| 从文件夹恢复                     | ✅ 按 `updatedAt` 取新，不覆盖更新的版本                                          |

### 3.4 上下文治理

| 功能                      | 状态                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| 实时 token 计量条         | ✅ 上限是**从引擎 `/props` 读的真实 ctx**（不是猜的）；超 60% 变黄、85% 变红                              |
| **只带最近 N 轮**（临时） | ✅ 实测：只影响本次发送，历史不动；计量条随之下降                                                         |
| **压缩上下文**（永久）    | ✅ 实测：让模型把更早内容写成摘要、**原文存档、可查看、可一键还原**；追问"只存在于被压缩部分"的信息仍答对 |
| 摘要用 `system` 角色      | ✅ 关键修正：放 user 消息里模型当"外部资料"（0/3 答对）→ 改 system 后 3/3                                 |
| 裁剪时保留 system 摘要    | ✅ 否则一裁剪模型立刻失忆                                                                                 |

### 3.5 多标签页

| 功能                                    | 状态                                                        |
| --------------------------------------- | ----------------------------------------------------------- |
| 跨标签同步（`storage` 事件 + 聚焦刷新） | ✅ 实测：A 页写入后 B 页列表自动从"4 轮"变"5 轮"并提示      |
| 同一会话并发编辑                        | ⚠️ 后写覆盖先写（无法合并）——建议一个会话只在一个标签页编辑 |
